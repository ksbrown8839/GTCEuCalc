Optimize in 5 steps
  1. Pick the target. Choose the product and the output rate you want.
  2. Set boundaries. Decide what your base already supplies, such as fluids, circuits, or stock parts.
  3. Choose recipe methods. Click a flow-map node, then choose the machine path or recipe variant.
  4. Enter built machines. Set how many machines you actually placed. Underbuilt groups cap real output.
  5. Limit input supply. Set available rates, use No limit for separately handled inputs, or click Make to expand them upstream.
